Политика конфиденциальности приложения «Маленький караван»

Дата публикации: 27 сентября 2026 года. Обновлено: 13 октября 2026 года

Настоящая политика описывает обработку данных при использовании мобильного приложения «Маленький караван» для Android.

1. Общие положения

Приложение предназначено для совместных прогулок детей и родителей по Троицку. Для работы отдельных функций приложение получает доступ к геолокации, камере и фотографиям на устройстве.

2. Геолокация

Приложение использует данные о местоположении устройства для отображения положения пользователя на карте, навигации по пешеходному маршруту и автоматического определения прибытия к точкам маршрута.

Данные о местоположении используются непосредственно на устройстве для работы функций приложения и не требуют создания учётной записи.

3. Камера и фотографии

Камера используется по инициативе пользователя для фотографирования во время прогулки. Пользователь также может выбрать фотографии из галереи устройства.

Фотографии и создаваемые приложением коллажи сохраняются на устройстве пользователя. Приложение не требует загрузки фотографий на сервер для работы основных функций.

4. Учётная запись

Регистрация и создание учётной записи в приложении не предусмотрены.

5. Реклама и аналитика

Приложение не содержит рекламных SDK и не предоставляет пользователю персонализированную рекламу. В приложении не предусмотрена отдельная система пользовательской аналитики или отслеживания поведения пользователей.

6. Хранение данных

Прогресс прогулки, найденные предметы и связанные с ними данные сохраняются локально на устройстве. Удаление приложения может привести к удалению этих локальных данных.

7. Сетевые сервисы

Для отображения карт и построения пешеходных маршрутов приложение может обращаться к используемым картографическим и маршрутизационным сервисам. При сетевых запросах соответствующие технические данные могут обрабатываться такими сервисами согласно их собственным политикам конфиденциальности.

Озвучка записана заранее и входит в состав приложения: голос рассказчика создан с помощью Яндекс SpeechKit, голос верблюжонка Троши — с помощью ElevenLabs. Во время работы приложение не обращается к этим сервисам и ничего им не передаёт.

8. Данные детей

Приложение предназначено для совместного использования ребёнком и взрослым. Приложение не требует регистрации ребёнка и не запрашивает его имя, дату рождения, контактные данные или иные персональные данные для создания профиля.

9. Изменение политики

Политика может обновляться при изменении функциональности приложения или требований к обработке данных. Актуальная версия размещается по постоянному адресу данной страницы.
