# Отзывы: Telegram-бот и функция Яндекс Облака

Как это работает:

1. На главной странице сайта человек пишет имя и отзыв и нажимает «Отправить».
2. Функция Яндекс Облака (`reviews/index.js`) пересылает отзыв вам в Telegram с кнопками
   **✅ Опубликовать** и **🗑 Удалить**. Сама функция ничего не хранит.
3. «Опубликовать» — функция дописывает отзыв в `data/reviews.json` на GitHub, и через минуту
   он виден на сайте у всех. У опубликованного отзыва остаётся кнопка **↩️ Снять с сайта**.

Хранится только то, что человек написал сам: имя и текст. Ни почты, ни телефона.

## Настройка (один раз)

### 1. Бот в Telegram
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → название (например, «Маленький караван — отзывы»)
   и имя бота латиницей, оканчивающееся на `bot`.
2. BotFather пришлёт **токен** вида `123456789:AA…` — это `BOT_TOKEN`.
3. Найдите своего бота в Telegram и нажмите **Старт** (иначе он не сможет вам писать).
4. Ваш **chat id**: напишите [@userinfobot](https://t.me/userinfobot) — он ответит числом `Id: …`. Это `ADMIN_CHAT_ID`.
   Чтобы отзывы приходили нескольким людям, впишите их id через запятую (`280752514,638077028`) — и каждый
   из них должен нажать **Старт** в боте. Опубликовать может любой; дважды один отзыв на сайт не попадёт.

### 2. Токен GitHub
GitHub → аватар → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** →
**Generate new token**:
- Repository access: **Only select repositories** → `malenkiy-karavan-web`;
- Permissions → Repository permissions → **Contents: Read and write**;
- срок — лучше подольше, например год (когда истечёт, кнопка «Опубликовать» покажет ошибку — выпустите новый).

Токен — как пароль: не показывайте его на экране и в переписке, вставляйте только в Яндекс Облако.

Скопируйте токен `github_pat_…` — это `GITHUB_TOKEN`.

### 3. Функция в Яндекс Облаке
1. [console.yandex.cloud](https://console.yandex.cloud) → **Cloud Functions** → **Создать функцию**, имя `karavan-reviews`.
2. На странице функции включите **Публичная функция**.
3. **Редактор** → среда выполнения **Node.js** (18 или новее) → способ «Редактор кода» →
   в файл `index.js` вставьте содержимое `reviews/index.js` из этого репозитория.
4. Точка входа: `index.handler`, таймаут: `30` секунд, память: `128 МБ`.
5. **Переменные окружения**:
   - `BOT_TOKEN` — токен бота;
   - `ADMIN_CHAT_ID` — ваш chat id;
   - `GITHUB_TOKEN` — токен GitHub;
   - `HOOK_SECRET` — любая длинная строка из латинских букв и цифр (например, 30 случайных символов).
6. **Сохранить изменения**.
7. Скопируйте адрес функции (`https://functions.yandexcloud.net/…`) и откройте его в браузере,
   дописав в конце `?setup=1`. Должно появиться `{"ok":true,…}` — бот подключён к функции.

### 4. Включить форму на сайте
Пришлите адрес функции — он впишется в `REVIEWS_URL` в `index.html`, и на главной появится форма
«Оставить отзыв».

## Если из Яндекс Облака не видно Telegram

`?check=1` пишет у `telegram` «нет ответа за 4 с», а у `github` — `ok`: интернет у функции есть,
но api.telegram.org из облака закрыт. Тогда функция ходит в Telegram через посредника — сервер,
с которого Telegram открывается (проверить на нём: `curl -sI https://api.telegram.org` — должен
прийти ответ `HTTP/… 302` или `200`).

На сервере с nginx добавьте в блок `server { … }` с https (часть адреса после `/tg-` придумайте
свою, это как пароль, чтобы посредником не пользовались чужие):

```nginx
location /tg-придумайте-длинное-слово/ {
    proxy_pass https://api.telegram.org/;
    proxy_ssl_server_name on;
    proxy_set_header Host api.telegram.org;
}
```

`nginx -t && systemctl reload nginx`, затем в функции добавьте переменную
`TG_API` = `https://ваш-сервер/tg-придумайте-длинное-слово` (без `/` на конце), сохраните
и снова откройте `?check=1` — у `telegram` должно стать `ok: бот @…`. Потом `?setup=1`.

## Стоимость
У Cloud Functions есть бесплатный объём вызовов в месяц; для отзывов его, скорее всего, хватит
с большим запасом. Точные условия — в тарифах Яндекс Облака.

## Если что-то не так
- Откройте адрес функции с `?check=1`: функция покажет, видит ли она Telegram и GitHub и все ли
  переменные заданы. «нет ответа за 4 с» — у функции нет выхода в интернет: в Яндекс Облаке
  активируйте платёжный аккаунт (без него облако работает в ограниченном режиме).
- Удалить или поправить опубликованный отзыв вручную: отредактируйте `data/reviews.json` на GitHub.
- Ошибки функции видны в Яндекс Облаке: функция → **Логи**.
