# Отзывы: проверка через GitHub

Как это работает:

1. На главной странице сайта человек пишет имя и отзыв и нажимает «Отправить».
2. Функция Яндекс Облака (`reviews/index.js`) создаёт задачу (Issue) «Отзыв: имя» в **закрытом**
   репозитории `qwest65/malenkiy-karavan-otzyvy`. Посторонние её не видят. Приложение GitHub
   на телефоне присылает пуш.
3. Решение — одним нажатием в задаче:
   - **Close issue** (закрыть как выполненную) — отзыв появляется на сайте примерно через минуту
     (первая строка задачи — оценка звёздочками; её можно поправить или стереть);
   - **Close as not planned** — отзыв не публикуется;
   - **Reopen** — опубликованный отзыв снимается с сайта.

   Опечатку можно поправить прямо в задаче (✏️ у текста) — на сайт уйдёт исправленный текст.
   Публикует workflow `moderation.yml` в репозитории отзывов: дописывает отзыв в `data/reviews.json` сайта.

Хранится только то, что человек написал сам: имя и текст. Ни почты, ни телефона.

## Настройка (один раз)

### 1. Закрытый репозиторий отзывов
GitHub → **New repository** → имя `malenkiy-karavan-otzyvy` → **Private** → галочка **Add a README** → **Create**.

### 2. Токен GitHub
Аватар → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** →
**Generate new token**:
- Repository access: **Only select repositories** → `malenkiy-karavan-web` и `malenkiy-karavan-otzyvy`;
- Repository permissions: **Contents: Read and write** и **Issues: Read and write**;
- срок — например, год (когда истечёт, отзывы перестанут приходить — выпустите новый и замените в двух местах ниже).

Токен — как пароль: не показывайте его на экране и в переписке.

### 3. Модерация в репозитории отзывов
1. В `malenkiy-karavan-otzyvy`: **Add file** → **Create new file** → имя `.github/workflows/moderation.yml` →
   вставить содержимое `reviews/moderation.yml` из репозитория сайта → **Commit changes**.
2. Там же: **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:
   имя `SITE_TOKEN`, значение — токен из шага 2.

### 4. Функция в Яндекс Облаке
Функция `karavan-reviews` → **Редактор**:
1. в `index.js` — содержимое `reviews/index.js`;
2. переменные окружения — только одна: `GITHUB_TOKEN` = токен из шага 2 (остальные можно удалить);
3. **Сохранить изменения**.

Проверка: откройте адрес функции с `?check=1` — должно быть
`{"github":"ok: qwest65/malenkiy-karavan-otzyvy (закрытый)"}`.

### 5. Пуш на телефон
- Установите приложение **GitHub** и войдите.
- В репозитории `malenkiy-karavan-otzyvy` нажмите **Watch** → **All Activity** (свои репозитории обычно уже отслеживаются).
- В приложении: **Settings** → **Notifications** → включите пуш для **Watching**.
- Чтобы отзывы видела и могла публиковать Анна: **Settings** репозитория → **Collaborators** → **Add people**
  (нужен её аккаунт GitHub) — и ей то же самое про приложение и Watch.

## Если что-то не так
- Убрать или поправить отзыв вручную — отредактируйте `data/reviews.json` в репозитории сайта.
- Отзыв не появился после закрытия задачи — в репозитории отзывов вкладка **Actions**: красный крестик
  у «Moderation» обычно значит, что истёк или не задан `SITE_TOKEN`.
- Ошибки функции — в Яндекс Облаке: функция → **Логи**; адрес функции с `?check=1` проверяет токен и репозиторий.
