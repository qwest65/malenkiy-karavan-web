# Счётчик запусков: пользуются ли прогулкой

Как это работает:

1. Прогулка (`progulka/app.js`, функция `ping`) присылает в функцию Яндекс Облака (`counter/index.js`) название события:
   `open` — открыли, `start` — начали прогулку, `finish` — дошли до конца, `install` — поставили на экран «Домой».
2. Функция кладёт в бакет Object Storage один пустой файл `день/событие/номер` (например `2026-11-02/start/lq3x9a1b2c`).
   Ни имени, ни адреса, ни номера человека нигде нет.
3. Раз в сутки workflow **Stats** (`.github/workflows/stats.yml`) читает список файлов бакета, считает по дням и пишет
   сводку: на вкладку запуска (Actions → Stats → Summary) и в ветку
   [`stats`](https://github.com/qwest65/malenkiy-karavan-web/tree/stats) — файл `STATS.md` открывается прямо на GitHub.
   Вручную: Actions → Stats → Run workflow.

Считаются **запуски**, а не люди: один человек, открывший прогулку трижды, даст три открытия.

## Настройка (один раз, в консоли Яндекс Облака)

### 1. Бакет
Object Storage → **Создать бакет** → имя (уникальное, например `karavan-stat-2026`) →
- **Доступ на чтение объектов** — ограниченный;
- **Доступ к списку объектов** — **публичный** (так GitHub читает список без паролей; в списке видны только даты и
  названия событий);
- **Доступ на чтение настроек** — ограниченный → **Создать бакет**.

### 2. Сервисный аккаунт
IAM → **Сервисные аккаунты** → **Создать** → имя `karavan-stat` → роль **`storage.uploader`** (загрузка объектов) в том же
каталоге, где бакет → **Создать**.

### 3. Функция
Cloud Functions → **Создать функцию** → имя `stat` → **Создать**. В редакторе:
- среда выполнения **Node.js 18** (или новее);
- файл `index.js` — содержимое `counter/index.js`, точка входа `index.handler`;
- тайм-аут 10 с, память 128 МБ;
- **сервисный аккаунт** — `karavan-stat`;
- **переменные окружения**: `BUCKET` = имя бакета; на время проверки ещё `DEBUG` = `1`;
- **Сохранить изменения**, затем на странице функции включить **Публичная функция** (иначе сайт не сможет её вызывать).

### 4. Проверка
Откройте «Ссылку для вызова» функции в браузере, дописав в конце:
- `?check=1` — должно быть `{"bucket":true,"token":true}`;
- `?e=open&debug=1` — должно быть `{"status":"stored"}`; в бакете появится папка с сегодняшней датой. Этот тестовый запуск
  посчитается как одно открытие — файл можно удалить в бакете.

После проверки уберите переменную `DEBUG` (или поставьте `0`).

### 5. Подключение
Имя бакета запишите в `counter/bucket.txt`, а ссылку на функцию — в `STAT_URL` в начале `ping()` в
`progulka/app.js` (затем увеличьте `VERSION` в `progulka/sw.js` и `APP_VERSION`). Пока `STAT_URL` пуст, прогулка
ничего не отправляет; пока `bucket.txt` пуст, workflow Stats ничего не считает.

Функция принимает события только со страниц сайта (по `Origin`/`Referer`), посторонние запросы не считает.
Расходы — доли копейки: хранится по пустому файлу на запуск, вызовы укладываются в бесплатный лимит.
