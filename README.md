# Маленький караван — веб-версия

**Прогулка по Троицку с верблюжонком Трошей для детей 4–7 лет и родителей.**
Работает прямо в браузере телефона: на iPhone и на Android, без установки.

### 👉 [qwest65.github.io/malenkiy-karavan-web](https://qwest65.github.io/malenkiy-karavan-web/)

<img src="images/qr.png" width="220" alt="QR-код прогулки" />

## Как пройти прогулку

1. Откройте ссылку на телефоне или наведите камеру на QR-код.
2. Нажмите «Начать прогулку» → «Идём!».
3. Телефон спросит про геопозицию — нажмите «Разрешить».
4. Дальше Троша ведёт сам: карта, повороты голосом, рассказы на каждой точке.

**Где работает** (проверено на нескольких iPhone, октябрь 2026):

| Где открыть | Геопозиция |
|---|---|
| Safari на iPhone | ✅ |
| Иконка на экране «Домой» iPhone | ✅ |
| Встроенный браузер Telegram | ✅ |
| Встроенный браузер MAX | ✅ (MAX спросит разрешение — нажмите «Разрешить») |

**Иконка на экране «Домой».** В Safari нажмите «Поделиться» → «На экран „Домой“».
Прогулка будет открываться как приложение — на весь экран и без интернета.

**Если геопозиция не находится** (например, когда-то нажали «Не разрешать»), на прогулке появится
жёлтая плашка — нажмите «Открыть в Safari» (на Android — «Открыть в браузере»).
Если кнопка не сработала, выберите «Открыть в браузере» в меню ⋯ или ☰ мессенджера.
Ещё проверьте, что приложению разрешена геопозиция: Настройки → MAX (или Telegram) → Геопозиция →
«При использовании приложения».

**Без геопозиции** прогулка всё равно проходится: у точки нажмите «🔔 Мы на месте!».

## Что умеет

- 🗺️ Готовые маршруты («Весь маршрут», «Крепость и собор», «Улица Климова», «Купеческий Троицк») и сборка своего.
- 🧭 Навигатор: карта поворачивается по пути, путь строится по улицам, повороты на плашке и голосом Троши.
- ✋ Карту можно двигать, увеличивать и вращать двумя пальцами; кнопка «▲С» разворачивает её на север. Через 8 секунд карта сама возвращается к вам.
- 👇 Нижняя панель сворачивается сама через 5 секунд, чтобы не закрывать карту; потянуть вверх — развернуть.
- 🔔 Прибытие на точку по GPS — постойте рядом 5 секунд, или нажмите «Мы на месте!».
- 🗣️ Рассказчик и Троша, вопрос с вариантами, игра на месте, справка для взрослых голосом.
- 📷 Фото на каждой точке, альбом найденных вещей и коллаж на лист A4 — его можно отправить, сохранить или распечатать на одну страницу.
- 🏅 Значок «Юный караванщик» за пройденный маршрут.
- 📶 После первого открытия работает без интернета (кроме подложки карты, которая запоминается по мере просмотра) — ход сохранения виден на главном экране в процентах.
- 💬 Открывается прямо в Telegram и MAX: ссылку можно просто отправить в чат.
- 📲 Можно поставить иконкой на экран «Домой» — и на iPhone, и на Android.
- 🔒 Ничего не собирает: фото и альбом хранятся только в телефоне.

## Где что лежит

| Путь | Что это |
|---|---|
| `index.html` | Страница приложения и карточка ссылки для мессенджеров |
| `app.js` | Вся логика: экраны, карта, навигация, прибытие, озвучка, фото и коллаж |
| `style.css` | Оформление |
| `sw.js` | Работа без интернета. **После любой правки увеличьте `VERSION`** — тогда телефоны заберут новую версию. Номер версии для людей — `APP_VERSION` в `app.js`, он виден внизу главного экрана |
| `manifest.webmanifest`, `icons/` | Название и иконки для установки на Android |
| `data/` | Маршрут, вопросы, пешеходные линии и улицы центра (из Android-приложения) |
| `audio/` | Озвучка: рассказчик — Яндекс SpeechKit, Троша — ElevenLabs (MP3) |
| `stickers/` | Наклейки: Троша, вещи, значок |
| `images/` | Картинка для карточки ссылки и QR-код |
| `vendor/` | Библиотека карты MapLibre GL JS 4.7.1 |
| `tools/build_web.py` | Обновляет `data/`, `audio/`, `stickers/` из Android-приложения |

## Откуда тексты и озвучка и от чего зависит сайт

**Сайт работает сам по себе.** Всё, что нужно прогулке, лежит в этом репозитории:
`data/` (маршрут, тексты, вопросы, пешеходные линии), `audio/` (озвучка) и `stickers/` (наклейки).
Телефон скачивает их отсюда, с `qwest65.github.io/malenkiy-karavan-web/`. Во время работы сайт
не обращается к Android-репозиторию — даже если его удалить, прогулка продолжит работать.
Из внешнего нужна только подложка карты OpenFreeMap.

**Оригинал текстов и озвучки — в Android-приложении.** Прогулка одна и та же в приложении и на сайте,
поэтому тексты, вопросы и озвучку правят в одном месте —
[qwest65/malenkiy-karavan](https://github.com/qwest65/malenkiy-karavan), — а сюда переносят копию
скриптом `tools/build_web.py` (ниже). Связь с Android-репозиторием есть только в этот момент:
без него скрипт не запустится, и тексты пришлось бы править прямо в `data/route.json`.

**Старый адрес.** Раньше веб-версия жила в Android-репозитории по адресу
`qwest65.github.io/malenkiy-karavan/app/`. Там остались два файла-перенаправления
(`docs/app/index.html` и `docs/app/sw.js`): старые ссылки и QR-коды ведут на этот сайт,
а у тех, кто открывал старый адрес, стирается прежняя сохранённая копия.

## Как обновить тексты или озвучку

Тексты, вопросы и озвучка общие с Android-приложением и правятся там,
в [qwest65/malenkiy-karavan](https://github.com/qwest65/malenkiy-karavan). Потом:

```bash
git clone https://github.com/qwest65/malenkiy-karavan ../malenkiy-karavan
pip install soundfile numpy lameenc
python tools/build_web.py ../malenkiy-karavan
```

и увеличьте `VERSION` в `sw.js`.

## Публикация

Сайт публикует GitHub Pages из ветки `main` (Settings → Pages → Deploy from a branch → `main` / `(root)`).
Изменения появляются по ссылке через 1–2 минуты после попадания в `main`.

Если карточка ссылки в Telegram старая — отправьте ссылку официальному боту
[@WebpageBot](https://t.me/WebpageBot), он обновит её.

MAX перечитывает карточку сам. Если всё же видна старая — отправьте ссылку с хвостиком,
например `https://qwest65.github.io/malenkiy-karavan-web/?v=3` (каждый раз новое число).
